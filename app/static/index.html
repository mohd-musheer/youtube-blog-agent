AI Blog Generator

Transform any YouTube video into a fully formatted blog post instantly.

API Documentation

Endpoint

POST /generate-blog

Description

Accepts a YouTube URL and processes it through an AI workflow graph to generate a cohesive blog title and formatted content.

Request Body (JSON)

{
  "youtube_url": "string (Valid YouTube URL)"
}

Response (JSON)

{
  "title": "string",
  "content": "string (Markdown formatted)"
}
